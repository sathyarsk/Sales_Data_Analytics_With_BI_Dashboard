# Sales_Data_Analytics_With_BI_Dashboard
Sales and Customer Analysis with BI Dashboard Automated

End-to-end sales analytics and predictive forecasting using PySpark, Spark SQL, and Google Sheet

This project focuses on analyzing sales and customer data to generate meaningful business insights. It uses PySpark and Spark SQL for data cleaning, transformation, and analysis, with Google Sheets for dashboard visualization and reporting.

The project also explores predictive sales forecasting using historical monthly sales data to understand potential future revenue trends.
